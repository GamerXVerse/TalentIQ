# Traditional vs. TalentIQ study protocol

> Status: designed, not yet executed. No participant results exist.

Use synthetic records. Counterbalance representative recruiting participants across a traditional resume-and-notes workflow and the TalentIQ web workflow. Measure capture time, review time, completeness, structural consistency, statement-level summary support, correction rate, decision confidence, and accessibility/usability observations.

## Reporting template

Record participant count and experience, task order, dataset version, medians and ranges, completeness percentage, supported-summary percentage, correction categories, confidence results, accessibility findings, limitations, and protocol deviations.
